Islamabad pollen counts

The Pakistan Meteorological Department measures pollen daily in sectors H-8, E-8, G-6 and F-10 and publishes it as a page you cannot query. This mirrors those numbers, keeps the history, and republishes them as open data.

latest.json · full CSV · manifest · source

This page updates only when someone in Pakistan opens it. PMD refuses requests from outside Pakistan, so no server anywhere can collect these numbers on a schedule. Opening this page from a Pakistani connection is what fetches the latest reading — including the visit you are making now. If nobody looks for a while, the figures below get old, and there is no way to recover the missed days afterwards because PMD keeps no archive.

How this stays up to date

We measured this across five networks: an Islamabad home connection and a Cloudflare Worker in the Islamabad colo both get through; a Worker in Frankfurt, GitHub Actions, and a US service network all get HTTP 403. So the fetch has to happen inside Pakistan, and only the fetch does. Opening this page asks a Cloudflare Worker — which runs at the edge nearest you, so in Islamabad for a Pakistani visitor — to refresh its cached copy of PMD. Automated CI then collects that copy a few times a day, parses it and publishes the result here. That is why a visit matters and why a quiet week leaves a gap.
